# Shared interview protocol assets

**Status: Not started (Phase 5).** This directory is reserved for the machine-readable, model-agnostic assets of the expert interview protocol (stage definitions, probe library, terminology glossary, locale strings) that both candidate architectures would consume.

The protocol itself is specified in [`docs/interview/expert-interview-protocol.md`](../docs/interview/expert-interview-protocol.md). Keeping the assets here, outside either implementation, is what lets Option A and Option B run the same scientific protocol.
